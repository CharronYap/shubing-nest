# 薯餅的小窩

在網頁上布置娃娃房間、用娃娃機夾娃娃和家具，每天陪八隻娃娃做幾件小事。可以登入雲端帳號，換裝置接著玩，也可以去朋友家看看、每天留一顆愛心。

## 直接玩

網頁版：https://charronyap.github.io/shubing-nest/

手機、電腦打開就能玩。push 到 main 之後，大約一兩分鐘網頁版會自動更新。瀏覽器會把檔案快取 10 分鐘，打開過舊版的人看不到新改的地方時，重新整理一次就好（電腦按 `Cmd + Shift + R`）。

手機可以加到主畫面當 app 用：iPhone 用 Safari 打開，按分享 →「加入主畫面」；Android 用 Chrome 的「安裝應用程式」或「加到主畫面」。從主畫面打開是全螢幕，沒有瀏覽器的網址列。沒有做離線快取，每次打開都是抓最新版，所以要有網路。更新這個設定（2026-11-26）以前就加過主畫面的，要把舊的圖示刪掉再加一次才會變全螢幕。

## 在自己電腦跑

改程式時用這個方式。不用安裝任何套件，Mac 內建的 Python 就能跑。

```bash
git clone https://github.com/CharronYap/shubing-nest.git
cd shubing-nest
python3 -m http.server 8765
```

瀏覽器打開 http://localhost:8765 就可以玩。要停下來時，在終端機按 `Ctrl + C`。

直接雙擊 `index.html` 多半也能開，但有些瀏覽器會擋本機檔案的存檔，建議用上面的方式。

用手機試玩：手機和電腦連同一個 Wi-Fi，把網址裡的 `localhost` 換成電腦的區域網路 IP（例如 `http://192.168.1.23:8765`）。

## 第一版有什麼

- **封面**：打開先看到封面，按中間的薯餅進房間，右上角的按鈕直接去娃娃機。
- **雲端帳號**：封面左上角的「登入」。可以用好友碼加朋友。沒登入也能玩，登入時會把這台的進度帶進帳號。設定和後台步驟在 `docs/CLOUD.md`。
- **跟蛋蛋島共用的幣**：小窩的幣和薯餅蛋蛋島的造型幣是同一個錢包（1 比 1），在哪邊賺、在哪邊花都算同一堆。帽子和衣服也共用：一邊買了、夾到了，另一邊也有。登入時用蛋蛋島同一組名字和密碼就會自動連上；已經登入的，在帳號視窗最下面打一次蛋蛋島的密碼。沒有蛋蛋島帳號的照舊自己算。要先在蛋蛋島的 Firebase 主控台發布一次規則，步驟在 `docs/WALLET.md`。
- **背景音樂**：一打開就放，音量放得比較小。手機和多數瀏覽器不准網頁自己出聲，這時碰一下畫面任何地方就會開始放。封面上的音符按鈕可以開關，關掉後這台裝置會記住，下次打開也不會放。房間裡沒有音樂鈕，要開關就按左上角回封面。
- **房間**：客廳、臥室、浴室三間。房間直接鋪滿畫面。下方的收納架點上緣的拉把（或往下滑）可以收成右下角的圓按鈕，房間會延伸到底，點圓按鈕再打開；這台裝置會記得上次是收著還是打開。收起來時牆的高度不變，多出來的空間都給地板。拖娃娃時圓按鈕會變淡讓開。娃娃可以拖來拖去，也能坐到沙發、床這些家具上。晚上七點到早上五點窗外會變成夜空，燈開著時房間跟白天一樣亮。
- **開燈關燈**：窗戶左邊的牆上有電燈開關，每個房間各自記得開或關。關燈後房間變暗，有檯燈的話只剩檯燈亮著。
- **娃娃機**：夾一次 2 枚幣。第一次進來送 20 枚，之後每天第一次打開送 10 枚。連續沒夾到時，第 10 次只要爪子底下有東西就一定夾到。
- **扭蛋**：娃娃機裡約兩成是扭蛋，開出來是家具、壁紙或小事要用的道具。湊齊雲朵系列（床、地毯、檯燈、蛋椅、相框）會送雲朵地板。
- **爪子**：一開始有兩款，夾到 3、8、15 次各解鎖一款。
- **每天的小事**：每天從已經有的娃娃裡抽 3 件，有的點娃娃幾下就好，有的要用扭蛋開到的道具。做完一件拿 2 枚幣。缺道具的那幾件會寫要什麼，旁邊有「去夾」可以直接去娃娃機；右上角的紅點只算現在做得到的件數。
- 一開始有 5 隻娃娃，另外 3 隻要從娃娃機夾。
- **娃娃相簿**：房間上方的相簿按鈕。一隻娃娃一頁，寫名字、個性和哪天來的；點娃娃聽過的話、一起做完的小事會收進來。還沒夾到的娃娃是灰色剪影。
- **你不在的時候**：隔 3 小時以上再打開，有的娃娃換了位置，龍龍、皮蛋、彈跳豬可能跑到別的房間，地上也可能多了葉子、拖鞋或稿紙。進房間時上方有一張便條，點一下收起來。地上的東西點一下收好，一天前 3 個各給 1 枚幣。家具不會被移動。
- **晚上看夢**：娃娃晚上會睡覺，都睡到早上 7 點。薯餅、蛋黃哥 10 點睡，皮蛋、貓咪老師、史努比、火腿 11 點睡，龍龍和彈跳豬玩到半夜 12 點才睡。點睡著的娃娃會跳一張夢卡，不會吵醒牠，也不扣任何東西。每隻每晚做一個夢（同一晚再點還是同一個），會先挑還沒看過的；看過的夢收進相簿那隻的「做過的夢」。
- **娃娃之間的感情**：兩隻娃娃放在同一個房間，待得越久越好，只會變好、不會變差。開著遊戲時每 5 分鐘算一次，你不在的時候也算（一次最多 60 分鐘）。一起待 20 分鐘「認識了」、90 分鐘「變熟了」、240 分鐘「好朋友」，相簿每一頁有「跟誰比較好」，用一到三顆心表示。龍龍和彈跳豬、皮蛋和史努比、火腿和貓咪老師、龍龍和火腿、薯餅和蛋黃哥這五對，剛變熟的那天會多排一件牠們一起的小事。
- **娃娃送的小禮物**：做完一件小事，大約四次有一次，那隻娃娃會送東西。貓咪老師送點心盒，彈跳豬送泡泡球，火腿給 1～3 枚零用錢，其他隻點心盒或泡泡球隨機。送過的東西會收進那隻娃娃的相簿頁。
- **去朋友家**：登入後，帳號視窗的好友清單點朋友的名字，就會進到對方的小窩。三個房間可以換著看，擺設、壁紙、開關燈和娃娃穿的衣服都照對方的樣子；只能看，不能拖、不能動家具，也不會改到任何人的存檔。點朋友的娃娃會冒一顆愛心。下面的「留一顆愛心」每個朋友一天能按一次（台灣時間 0 點換日）。自己這邊只看得到「今天收到幾顆」，不會知道是誰送的，也沒有排行和通知。朋友要登入後打開過一次小窩，房間才會放上雲端讓別人看。
- **玩偶衣櫃**：點臥室的衣櫃，或相簿裡的「換衣服」。15 頂帽子（加上 12 月送的紅圍巾）、14 套衣服，用幣買（帽子 8～20 枚，衣服 12～36 枚），扭蛋開出來也有約三成五是衣櫃裡還沒有的東西。一開始就有水手服。買來的東西八隻共用，每隻各自記得穿什麼，換好會說一句話。帽子八隻都能戴；衣服目前只有薯餅和蛋黃哥穿得上，其他隻會寫「這套還在做」。舊存檔會在臥室多送一個衣櫃。
- **季節和節日**：日子到了就自己出現，錯過也沒關係，明年同一個時候會再來，也不用每天上線。農曆新年前後兩週內打開一次，火腿給一個紅包（6 枚幣，每年一次），收納架多燈籠和春聯；4 月櫻花窗貼、7 月西瓜坐墊、中秋前後兩週月亮燈和玉兔、10 月 25 日到 11 月 7 日南瓜燈、12 月小松樹和雪花窗貼，12 月衣櫃還會多一條紅圍巾（不用買，帽子格最後一格）。家具和圍巾都是送的，拿過就一直留著，放進收納架的「季節」那組，要不要擺出來自己決定，擺在別的房間的會變淡、旁邊標房間，點一下就搬過來。窗外跟著月份換：春天飄花瓣、夏天綠色山坡、秋天落葉、冬天下雪。娃娃來小窩滿一年那天會說一聲，第一次碰到時收納架多一個週年蛋糕。新年、中秋、萬聖節、聖誕節那幾天，每天的小事會多一件節日的，做完收進相簿，沒做到也不會留下空格。
- **拍照**：房間右上角的相機按鈕。把現在的房間（牆紙、地板、家具、娃娃穿的衣服、開關燈）畫成一張直式照片，下面寫小窩的名字和日期。有幾隻娃娃會在照片裡有自己的樣子：史努比會歪頭，彈跳豬常常跳起來，火腿會在角落寫一句吐槽，睡著的娃娃有 z。手機上按「存下來」會跳出分享選單，可以存到相簿；電腦直接下載。拍到的娃娃，相簿那頁會多一行「○月○日一起拍了照」（同一天只記一次，留最近 12 天）。去朋友家時不能拍。
- **信箱**：相機左邊的信封。娃娃會寫信給你，一天最多寄一封（「小窩更新了」不算）：每隻來小窩之後寫一封「你好」，跟同一隻一起做完 5、10、20 件小事各一封，來小窩滿一年那天打開會收到一封，隔 3 天以上再打開時，其中一隻寫一封「你不在的時候」，說說牠這幾天在做什麼。每隻照自己的個性寫：薯餅寫到一半睡著、彈跳豬字特別大、龍龍先給一片葉子（點一下翻過來才是信）、史努比寫連載小說、皮蛋會夾一隻拖鞋、火腿吐槽房間。一天第一封娃娃的信大約一半會附點心盒或泡泡球（貓咪老師不附，彈跳豬附泡泡球），按「收下」放進道具。小窩有更新時薯餅會寫一封「小窩更新了」。信不會過期，附件沒領也一直留著；信箱最多放 30 封，滿了只會清掉看過、附件也領了的舊信。寫過的信收進相簿那隻的「寫給你的信」。每隻每種信有好幾個版本（你好 4、做了幾件事 8、滿一年 6、你不在的時候 14），先寫沒寫過的，都寫過才重複；史努比的小說有兩部共 20 章。登入雲端帳號的人，娃娃的信可以改請 AI 照那隻的個性現寫一封（程式做好了、還沒打開，步驟在 `docs/AI-LETTERS.md`）；沒打開或寫不出來時用原本寫好的信。

- **咕嚕嚕秘密花園**（門外）：上面房間鈕最右邊的花園。12 塊地，一開始有石頭、草叢和空地。自己一天可以動手 3 次（搬石頭、拔草、翻土、種種子、澆水），用完就是「今天先這樣」，明天再來，沒用完也不會怎樣。娃娃一天各幫一次忙：龍龍敲石頭（有時敲出 1 枚幣），皮蛋和史努比翻土（皮蛋偶爾挖到拖鞋，史努比會挖到小說的第一頁），彈跳豬在空地噴水變池塘或一次澆一整排，貓咪老師坐在花圃旁招來蝴蝶或小鳥。翻土會挖到草、花或樹苗的種子，信件附件有時也會變成種子；種下、澆水，隔天就長好，沒澆水就一直是種子等你。薯餅可以在草地睡一晚，隔天旁邊多一棵樹；蛋黃哥可以趴在空地一晚，隔天孵出蘑菇燈、雲朵長椅或小木牌。去過夜的娃娃在收納架會標花園，點一下就叫回來，隔天早上也會自己回房間。娃娃在花園做過的事收進相簿的「花園」。去朋友家時看不到花園。

- **送娃娃**：登入以後，同一隻娃娃有兩隻以上的，可以從信箱下面的「送娃娃給朋友」送一隻給好友，再從六句寫好的話裡挑一句。朋友的信箱最上面會出現「○○從××家來了」，按「讓牠進來」娃娃才算到他家，同時留一封「從××家來的」信，相簿翻得到。朋友還沒開門前，寄的人可以在信箱「在朋友門口等的」那一列收回。同時最多 3 隻在朋友門口，一天最多送 3 次。送出去的娃娃不會過期、不會自己退回，朋友沒開門也不會怎樣，不提醒、不倒數。

第五版是朋友之間的玩法，都要登入、互加好友才有。朋友沒來不會少東西，沒有紅點、不倒數、不排名。

- **自己打字**：訪客簿、過夜的小紙條、送娃娃的那句話（各 40 字以內）和明信片（80 字以內）可以自己打字。要收的人自己加過寫的人為好友才寫得進去（對方單方面加你不算），字數上限雲端規則也會擋；畫面上一律當純文字顯示；收到的人和寫的人都能刪。有人寫了不舒服的話，刪掉那一則，再到帳號的好友清單按「移除」，他就寫不進來了。沒有做髒話過濾。好友清單上，對方加了你、你還沒加他的會有一顆「加回去」；你加了他、他還沒加你的會寫「還沒加你」，這時候看不到他的訪客簿、不能寄明信片給他，送娃娃只能選寫好的句子。

- **訪客簿和貼紙**：房間左上角的小本子。去朋友家時點開，貼一張貼紙、寫一句話（可以不寫），每個朋友每天一則，跟愛心分開算。貼紙一開始是八隻娃娃的臉；有季節家具、貓咪老師在花園招來過蝴蝶或小鳥，就各多一張。自己家點開是朋友留的，最新的在前面，留最近 50 則。**訪客簿的字，來你家的朋友都看得到。** 主人第一次看到新的一則時，貼紙上那隻娃娃在房間裡跳一下。

- **願望清單**：相簿裡還沒來的娃娃，點星星放進願望清單，最多 3 隻。朋友來家裡時，下面有一塊小木牌「想要：○○、○○」；朋友剛好同一隻有兩隻以上，旁邊出現「送○○過去」，按了直接走送娃娃。夾到或收到之後自動從清單拿掉。這版只放娃娃。

- **幫朋友的花園澆水**：去朋友家時，上面多一顆花園鈕（朋友去過自己的花園才有）。種下去還沒長大的地可以幫忙澆一次，每個朋友每天一次，澆的人拿 1 枚幣。朋友下次打開小窩，那塊地直接長大一步，地上插一支小牌子「○○來澆過水」，點那塊地可以收掉。朋友幫忙不算自己一天 3 次；一天最多收 3 個朋友的，多的留到隔天。

- **娃娃去朋友家過夜**：去朋友家時按「讓娃娃過夜」選一隻，牠去住一晚。牠還是你的，跟送娃娃是兩件事；一次只能有一隻在外面。自己家牠原本的位置留一張小紙條，點紙條可以提早叫回來。朋友那邊牠出現在客廳，頭上有名牌，主人可以點牠冒愛心、拖到想放的地方、塞一張小紙條讓牠帶回去，也可以送牠回家（框裡打了字直接按「送牠回家」也會帶著紙條）。隔天早上 5 點以後打開小窩牠就回來，帶一封過夜日記（照朋友家擺的家具和娃娃寫）加主人塞的小紙條，收在上面的「朋友」→「他那邊來的」，那一行直接寫著紙條的內容（沒登入時在信箱）；帶著紙條回來的那一次，房間裡會跳一張卡片把紙條給你看。相簿記一行「○月○日去○○家過夜」。朋友一直沒打開遊戲也沒關係，牠照樣回來、日記照樣有。被提早送回家、自己提早叫回來、回家那時候還沒連上雲端，紙條都不會不見。

- **明信片**：登入後，拍照的預覽多一顆「寄給朋友」。選一個朋友、寫一句話，一天最多寄 3 張。朋友的信箱最上面多一張明信片，點開看那間房間，下面是寫的話、名字和日期，可以存成圖片。不傳圖片檔，傳的是那間房間的擺法，朋友那邊重新擺出來。信箱留最近 10 張。花園的照片還不能寄。

賺幣、家具、場景（2026-11-26）。使用者玩了之後回報幣不夠用、家具想要多一點、場景想要多點變化。

- **幣怎麼來**：每天第一次打開 20 枚；做完一件小事 3 枚；撿地上的小東西一天最多 3 枚；每天第一次夾娃娃不用幣。點上面的幣，或幣不夠要夾娃娃時，會列出「現在可以賺幣的事」，點了直接過去。認真玩一天大約 50～60 枚。
  - **電視小遊戲**：點客廳的電視。接點心（貓咪老師左右接掉下來的點心，30 秒）和翻牌（12 張找一樣的兩張）。每天前 3 局照成績 3～5 枚，之後每局 1 枚，不限次數。漏接、翻錯都不扣東西。
  - **多的娃娃去打工**：同一隻有兩隻以上，多的那隻可以去娃娃機當店員，每隻一天 2 枚，最多 3 隻，隨時叫回來。好幾天沒來也只領一次，不會被扣。
  - **花園收成**：花圃每天摘一次花，樹兩天一顆果子，拿去小店一個換 1 枚。不算自己一天 3 次。
  - **愛心換幣**：朋友留一顆愛心多 1 枚（一天最多 5 枚），去朋友家留愛心自己也拿 1 枚。
  - **里程碑**：每項只給一次。第一次遇到每隻娃娃 5 枚、湊齊一個家具系列 10 枚、跟一隻娃娃做完 10／30 件小事各 10 枚、花園的石頭草叢都清掉 20 枚。已經達成的，更新後第一次打開一次補發。

- **火腿的小店**：房間左上角的小店鈕。每天擺 6 件還沒有的家具、壁紙、地板，隔天換一批。小東西 10 枚、一般 15～25 枚、大件 30～40 枚、壁紙地板 20 枚。娃娃機的扭蛋照舊夾得到家具，小店是另一條路；季節家具和湊齊系列送的不賣。收成的花和果子在這裡換幣。

- **家具**：一般家具從 18 件加到 60 件，壁紙 11 款、地板 10 款。都是用程式畫的，沒有用外面的圖。
  - 八隻娃娃的專屬家具（吊床、懶骨頭、拖鞋架、彈簧床、點心櫃、山洞帳篷、寫字桌、小講台）：那隻娃娃放上去會做自己的動作，別隻放上去是一般坐姿。湊齊送全家福相框牆。
  - 甜點系列（湊齊送奶油壁紙）、森林露營系列（送草皮地板）、海邊系列（送海浪壁紙）、太空系列（送星空地板），各 6 件。
  - 牆上的東西 3 件、魚缸（魚會游，貓咪老師會盯著看）、廚房 3 件、閣樓 3 件。

- **天色和天氣**：窗外分清晨、白天、傍晚、晚上四段，開著燈的房間光線也帶一點顏色。天氣照日期算出來（晴天五成、多雲三成、下雨兩成），同一天每個人看到的一樣；下雨隔天早上有機會出現彩虹。下雨天多一件下雨的小事，花園不用澆水。

- **新房間**：廚房和閣樓。小店最前面賣「廚房的鑰匙」「閣樓的梯子」，各 40 枚，買了上面多一顆房間鈕（超過四顆可以左右滑）。廚房多幾件跟吃有關的小事；閣樓是斜屋頂和圓天窗，晚上偶爾有流星。

- **上面的按鈕**：第一排是回封面、地圖鈕、幣、相機；第二排左邊是娃娃機和小店一組，右邊是信箱、今天的小事一組（去朋友家時多一顆訪客簿）；第三排左邊是相簿和本子一組，右邊是朋友。點本子會在按鈕下面跳出一張小卡，裡面是紀念冊、旅行、花園（花和小客人）三本。同一組的按鈕包在同一個膠囊形的底裡。娃娃機那一頁，回房間、幣的位置跟房間頁一樣。回封面不會登出或清東西，再按開始回到剛剛那一間。

- **看得出自己在哪一間**：最上面中間的地圖鈕寫著現在這一間的名字，左右的箭頭換到上一間、下一間（不用左右捲），換房間時跳一張房間名稱的小牌子。點地圖鈕中間是小屋地圖：整棟小屋的剖面圖（紙雕的紅瓦屋頂，閣樓在屋頂底下，每一間畫著自己的家具，門外是浮在雲上的花園），看得到每一間的壁紙、有沒有開燈、哪幾隻娃娃在裡面，點一間就過去。每一間有自己固定的樣子，換壁紙也認得出來：客廳是大窗戶和一扇通往花園的門，臥室是小窗戶和星星小夜燈，浴室下半截是磁磚、小窗在高處，廚房窗戶下面是流理台、牆上一排掛勾，閣樓是斜屋頂和圓天窗。房間左右兩邊是通往隔壁的門口，門框上有隔壁那一間的圖示，點了過去。

- **娃娃自己動**：娃娃每隔一陣子自己做一件事：一跳一跳到別的位置、找空座位坐、去自己的專屬家具、原地打哈欠或跳兩下、冒一句自言自語，晚上自己找地方睡。每隻照個性不一樣（皮蛋一直跑、蛋黃哥幾乎不動、薯餅很慢）。你擺的位置是牠的「家」，牠晃出去兩三次會自己回來；晃到哪裡不存檔，重新打開或換房間回來都從家開始。抓起一隻在外面晃的娃娃，放下去的地方就是新的家，牠會先乖乖待一分鐘。拖東西、開著面板、拍照時全部停下來；同時最多兩隻在移動。小屋地圖最下面有開關「讓娃娃自己玩」，預設開。

- **兩隻互動和串門子**：娃娃會跳到另一隻旁邊，面對面講兩句（28 對各有自己的對話）、一起跳、一隻跑一隻追、搶同一個座位；每互動一次交情加一點。偶爾會吵架（一天最多一次），點其中一隻就和好，不管牠們 30 分鐘後也會自己和好，不會扣交情。娃娃也會自己跳到房間邊的門口去隔壁，過一陣子回來；隔壁的娃娃會過來坐一下（可以點、不能拖）。小屋地圖顯示的是現在誰在哪一間。點娃娃時牠會歪頭看你。

- **玩偶之間的互動**（照家裡真的玩偶會做的事，一組一組加，程式在 `js/duo.js`）。第一組：**蛋黃哥側著塞進龍龍裡**。蛋黃哥和龍龍在同一間、都醒著、龍龍站在地上的時候，蛋黃哥有時候會跳到龍龍旁邊，往龍龍那邊倒下去，側躺著扭啊扭地從龍龍側邊擠進去；擠進去之後龍龍鼓一下，變成使用者照片裡的樣子（龍龍長長一條，蛋黃哥只露出頭；圖是那張照片去背、加白邊，`img/duo/egg-dino.webp`）。在裡面待 1 分半～3 分半，龍龍照樣左右跳、講話，兩隻輪流講幾句，時間到了蛋黃哥從同一邊側著擠出來、站起來。出來之後隔 4～8 分鐘才會再塞，沒塞的時候蛋黃哥也比較常待在龍龍旁邊。點露出來的頭是蛋黃哥講話，點龍龍的身體是龍龍講話；拖龍龍會兩隻一起拿走，把龍龍放到座位上蛋黃哥就出來。拍照拍得到照片那個樣子。相簿裡兩隻的頁面有「小習慣」：一共塞了幾次、第一次是哪天。跟娃娃自己動一樣不存位置，重新打開、換房間都從家開始；「讓娃娃自己玩」關掉、減少動態效果時不會塞。

- **小劇場**：幾隻娃娃真的在房間裡演一小段：走位、頭上輪流冒對話、做動作。每天自動準備 3～5 段，條件到了（演員都在這一間、需要的家具在），帶頭那隻頭上冒「！」，點了才開始演；沒點也不會消失，當天都在。有些演到一半會問你，選的不一樣結局不一樣。看完收進相簿可以重看，每一段第一次看完給 1 枚幣。第一批 40 段（每隻自己的 16 段、兩隻一組 16 段、三隻以上 4 段、跟家具有關 4 段），連續劇 3 條各 4 集（點心櫃失竊案、邪惡豬排博士、薯餅找床），前一集看過、隔天才排下一集。「今天的小事」做完一件時，有關的娃娃會在房間裡跳一下，上面顯示結果。劇本在 `js/skitdata.js`，加新的不用改程式。

- **出遊背景**：拍照的預覽下面可以選公園、海邊、夜市，重拍一張換背景的。只是換背景，不是新房間。

## 存檔和重來

沒登入時，進度只存在這台裝置的瀏覽器（`shubingNest.v1`）。登入後存在雲端的 `nestSaves/{uid}`，這台裝置另外留一份 `shubingNest.v1.u.{uid}`，換裝置登入同一個帳號就能接著玩。

訪客想從頭玩：瀏覽器開發者工具 → Application → Local Storage → 刪掉 `shubingNest.v1`，或在 Console 輸入：

```js
localStorage.removeItem('shubingNest.v1'); location.reload();
```
