# 跟薯餅蛋蛋島共用的錢包

2026-11-26 加的。小窩的幣和蛋蛋島的造型幣變成同一個錢包：1 比 1，在哪邊賺、在哪邊花都算同一堆。兩邊的價錢都沒有改。

## 玩家看到的

- **登入小窩的時候**，會用同一組名字和密碼順便登入蛋蛋島的帳號。連上之後，兩邊原本的幣合在一起（小窩原本的幣 + 蛋蛋島原本的造型幣）。
- **已經登入小窩的人**：封面左上角的帳號 → 最下面「跟蛋蛋島共用的幣」→ 打一次蛋蛋島的密碼 → 連起來。名字不一樣也可以改。
- 蛋蛋島那邊不用做任何事：登入了就自動用錢包。衣櫃上的數字會寫「幣（跟小窩共用）」。
- **帽子和衣服也共用**（同一天後來加的，使用者說「錢難賺，兩邊的衣服和配件其實會重複，我一邊買了另外一邊也有」）：
  兩邊的 14 頂帽子、14 套衣服本來就是同一批（小窩的衣櫃是從蛋蛋島抄的）。在小窩買的、夾到的，或在蛋蛋島兌換、拿星星、開寶箱、走到那一關解鎖的，
  另一邊都直接算有，不用再花幣。連上時兩邊有的合在一起，之後有新的，下次對帳就帶過去，跳一句「從○○帶來 N 件衣服和配件」。
  只有一邊有的東西（小窩的紅圍巾、蛋蛋島的消除特效、底座、棋盤主題、頭像外圈）不共用。
- 沒有蛋蛋島帳號、名字或密碼不一樣：連不上，小窩的幣照舊自己算，不會怎樣。
- 在小窩登出，也會順便登出這台裝置上小窩連的蛋蛋島帳號（不會影響蛋蛋島網頁本身的登入）。

## 上線前要在主控台做的事（只要做一次）

1. 打開 <https://console.firebase.google.com/>，選蛋蛋島的專案 **plush-crush**。
2. 左邊「建構 → Firestore Database」→ 上面的「**規則**」分頁。
3. 把裡面全部刪掉，換成蛋蛋島 repo（BONK520/shubing）的 `firestore.rules` 整份內容，按「**發布**」。
   這次只多了一段 `wallets`，其他段落沒有動。
4. 小窩和蛋蛋島兩邊的分支都合進 main，等 GitHub Pages 更新（一兩分鐘）。

順序沒關係：規則還沒發布時，兩邊讀寫錢包都會被擋，幣照舊各算各的，不會少，也不會出錯；發布之後下次打開就會接上。

萬一連的時候小窩說「蛋蛋島那邊還不讓小窩的網址登入」：Google Cloud 主控台 → plush-crush 專案 →「API 和服務 → 憑證」→ 網頁用的那把 API 金鑰，
如果「應用程式限制」設了網站，加上 `charronyap.github.io/*`。沒設限制就不用管（我從這裡看不到有沒有設，連得上就是沒問題）。

## 怎麼做的

錢包放在蛋蛋島的 Firebase 專案 plush-crush：`wallets/{蛋蛋島的帳號 id}`

| 欄位 | 意思 |
| --- | --- |
| `coins` | 兩個遊戲共用的幣 |
| `egg` | `{e, p}`：蛋蛋島已經算進錢包的造型幣，e 是賺到的總數（三星＋寶箱），p 是兌換掉的總數。兩個都只會變多 |
| `nest` | `{小窩的帳號 id: 1}`：哪些小窩帳號已經把原本的幣放進來過，同一個帳號換裝置不會再放一次 |
| `looks` | `['hat.bow', 'outfit.wizard', …]`：兩邊擁有的帽子和衣服合在一起，只會變多（最多 100 件） |
| `t` | 最後一次改的時間 |

- **小窩**（`js/wallet.js`、`js/account.js`）：用第二個 Firebase app 登入 plush-crush。`S.coins` 照舊是畫面上的數字，所有花幣、賺幣的程式都沒改。
  存檔記 `S.earn.wb`（上次對帳時錢包的數字）和 `S.earn.wu`（連的是哪個蛋蛋島帳號）。幣有變動，等 2 秒對一次帳：
  錢包 += S.coins − wb，再把 S.coins 換成錢包的數字。回到分頁、每兩分鐘也看一次（蛋蛋島那邊可能賺了或花了）。
  這台裝置記 `shubingNest.egg.{小窩帳號 id}` = 連的蛋蛋島帳號 id；登入的蛋蛋島帳號不是它就不碰錢包。
- **蛋蛋島**（`js/cloud.js` 的 `walletEgg`、`js/cosmetics.js` 的 `coins`、`js/main.js` 的 `walletSync`）：
  造型幣照舊用「三星＋寶箱 − 兌換掉的」算出 e、p，比錢包記的多出來的部分加減進 coins。
  只看多出來的部分，所以舊裝置上的存檔比較少也不會把錢包扣回去。畫面上的數字 = 錢包 + 這台還沒算進去的。
- 帽子和衣服：小窩把 `S.closet` 裡的帽子和衣服放進 `looks`，`looks` 裡小窩認得、還沒有的放進 `S.closet`；
  蛋蛋島把解鎖了的帽子和衣服（`closet.myLooks`）放進 `looks`，`looks` 裡有的在 `isUnlocked` 直接算解鎖（不算兌換，不扣幣）。
- 兩邊都用 transaction 寫，同時在兩個遊戲裡賺或花也不會蓋掉對方的。錢包不會變成負的。

## 知道的限制

- 兩台裝置同時離線、各自花幣，回來時錢包可能比實際多一點（不會變少）。
- 1 比 1 是使用者選的：小窩一天大約賺 50～60 枚，蛋蛋島的衣服 2～10 枚，所以連上之後蛋蛋島的東西很快就買得到。要改比例的話要兩邊一起改。
- 測試：`?emu=1`（模擬器）時小窩不連蛋蛋島。
